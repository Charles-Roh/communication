    16차시: 다중화란 무엇인가 — 하나의 채널로 여러 신호 보내기¶

    ⏰ 50분 · 다중화(Multiplexing) · FDM · TDM · 난이도 ●●●○○

    학습목표: 다중화의 원리를 이해하고, FDM과 TDM의 동작 방식을 비교·설명할 수 있습니다.

    오늘의 질문: "라디오에서 채널을 돌리면 다른 방송이 나오고, 전화기 한 회선에 수십 통화가 동시에 이루어지는 것은 어떤 원리 덕분일까요?"

    학습 목표¶

    • 다중화의 정의와 필요성을 실생활 사례를 들어 설명할 수 있다.
    • FDM(주파수 분할 다중화)의 원리와 특징을 설명할 수 있다.
    • TDM(시분할 다중화)의 원리와 FDM과의 차이를 비교하여 설명할 수 있다.

    🧠 핵심 개념 ①: FDM¶

    주파수 대역을 나누어 여러 신호를 동시에 전송하는 방식

    🧠 핵심 개념 ②: TDM¶

    시간을 쪼개어 여러 신호를 번갈아 전송하는 방식

    🔧 따라하기 실습¶

    FDM·TDM 주파수-시간 배분표 직접 그려보기

    📝 형성 평가¶

    객관식 3문항 + 서술형 1문항으로 이해도 점검

    ⏱️ 수업 흐름¶

    1단계: 도입 — 왜 다중화가 필요한가 (8분)¶

    고속도로 차선 비유를 통해 다중화의 개념과 필요성을 파악합니다. 하나의 통신 채널을 여러 사용자가 공유해야 하는 현실적 이유를 확인합니다.

    2단계: 개념 탐구 ① — FDM (12분)¶

    주파수 분할 다중화의 원리를 라디오 방송 채널 배분에 비유하여 학습합니다. 보호 대역의 역할과 FDM의 장단점을 정리합니다.

    3단계: 개념 탐구 ② — TDM (12분)¶

    시분할 다중화의 원리를 회전문 비유로 학습합니다. 동기식 TDM과 비동기식 TDM의 차이를 이해하고, FDM과 비교·정리합니다.

    4단계: 따라하기 실습 — 배분표 설계 (10분)¶

    직접 주파수-시간 배분표를 작성하며 FDM과 TDM의 자원 분배 방식을 체득합니다.

    5단계: 평가 및 성찰 (8분)¶

    형성 평가 문제를 풀고, 학습 목표 달성 여부를 자가 점검합니다. 다음 차시 내용을 미리 확인합니다.

    📚 왜 이걸 배우나요?¶

    여러분이 스마트폰으로 영상 통화를 하는 그 순간에도, 같은 기지국에 연결된 수백 명의 다른 사용자가 동시에 데이터를 주고받고 있습니다. 만약 한 사람이 통화를 끝낼 때까지 다른 사람이 기다려야 한다면, 현재의 통신 시스템은 성립하지 않습니다.

    다중화(Multiplexing) 는 이 문제를 해결하는 핵심 기술입니다. 하나의 물리적 채널에 여러 신호를 동시에 실어 보내는 방법이며, 현대 통신 시스템의 효율성을 결정짓는 근본 원리입니다. 공공기관 통신이론 시험에서도 FDM과 TDM은 거의 매 회차 출제되는 핵심 주제입니다. 이번 차시에서 두 가지 방식의 원리와 차이를 확실히 정리하겠습니다.

    📚 핵심 개념 설명¶

    1️⃣ 다중화의 정의와 필요성¶

    비유: 고속도로 차선¶

    편도 1차선 도로에서는 한 번에 한 대의 차만 지나갈 수 있습니다. 교통량이 늘면 도로를 새로 건설해야 합니다. 그런데 같은 도로 폭을 여러 차선으로 나누면, 여러 대의 차가 동시에 통행할 수 있습니다. 도로를 새로 깔지 않고도 효율을 높인 것입니다.

    통신에서도 마찬가지입니다. 하나의 전송 매체(광케이블, 동축 케이블, 무선 주파수 대역 등)는 물리적으로 하나입니다. 그러나 이 하나의 채널을 논리적으로 여러 조각으로 나누면, 여러 사용자의 신호를 동시에 실어 보낼 수 있습니다.

    정의¶

    다중화(Multiplexing) 란 하나의 고속·광대역 통신 채널을 여러 개의 저속·협대역 채널로 나누어, 복수의 신호를 동시에 전송하는 기술입니다.

    다중화를 수행하는 장치를 다중화기(MUX, Multiplexer) 라 하고, 수신 측에서 다시 개별 신호로 분리하는 장치를 역다중화기(DEMUX, Demultiplexer) 라 합니다.

    다중화 시스템의 기본 구조¶

    아래 다이어그램은 다중화 시스템의 전체 흐름을 보여줍니다.

    flowchart LR A1["신호 1"] --> MUX["다중화기<br/>(MUX)"] A2["신호 2"] --> MUX A3["신호 3"] --> MUX MUX -->|"하나의 채널"| CH["전송 매체"] CH --> DEMUX["역다중화기<br/>(DEMUX)"] DEMUX --> B1["신호 1"] DEMUX --> B2["신호 2"] DEMUX --> B3["신호 3"]

    왼쪽의 여러 신호가 MUX에서 하나의 채널로 합쳐지고, 전송 후 DEMUX에서 원래의 개별 신호로 분리됩니다.

    다중화가 필요한 이유¶

    이유 설명
    경제성 전송 매체(광케이블, 위성 등)는 설치 비용이 높습니다. 하나의 매체로 여러 신호를 보내면 비용을 절감할 수 있습니다.
    대역폭 활용 전송 매체의 대역폭이 개별 신호의 대역폭보다 훨씬 넓은 경우, 나머지 대역폭이 낭비됩니다. 다중화로 이를 효율적으로 사용합니다.
    관리 편의성 물리적 회선 수를 줄이면 유지보수와 관리가 간편해집니다.

    다중화의 주요 분류¶

    mindmap root((다중화 방식)) FDM 주파수 분할 아날로그 방식 기반 TDM 시간 분할 디지털 방식 기반 CDM 코드 분할 CDMA 이동통신 WDM 파장 분할 광통신 전용

    이번 차시에서는 FDM과 TDM을 집중적으로 다룹니다. CDM과 WDM은 이후 차시에서 학습하게 됩니다.

    2️⃣ FDM — 주파수 분할 다중화¶

    비유: 라디오 채널 다이얼¶

    여러분이 자동차에서 라디오 주파수를 돌릴 때, 88.1 MHz에서는 A 방송이, 91.9 MHz에서는 B 방송이, 95.1 MHz에서는 C 방송이 들립니다. 이 세 방송은 같은 공기라는 하나의 전송 매체를 공유하면서도, 서로 다른 주파수 대역을 사용하기 때문에 동시에 전송이 가능합니다. 이것이 바로 FDM의 원리입니다.

    정의¶

    FDM(Frequency Division Multiplexing, 주파수 분할 다중화) 은 전송 매체의 전체 대역폭을 여러 개의 비중첩(non-overlapping) 주파수 대역으로 나누고, 각 대역에 하나의 신호를 할당하는 다중화 방식입니다.

    FDM의 동작 원리¶

    FDM의 핵심은 변조(Modulation) 입니다. 각 입력 신호를 서로 다른 반송파 주파수(Carrier Frequency) 로 변조하여 주파수 대역을 이동시킵니다. 이전 차시에서 학습한 AM, FM 변조가 여기에 활용됩니다.

    아래 다이어그램은 FDM의 동작 과정을 단계별로 보여줍니다.

    flowchart TD S1["신호 1<br/>(0~4 kHz)"] --> M1["변조기 1<br/>반송파 f₁"] S2["신호 2<br/>(0~4 kHz)"] --> M2["변조기 2<br/>반송파 f₂"] S3["신호 3<br/>(0~4 kHz)"] --> M3["변조기 3<br/>반송파 f₃"] M1 --> COMBINE["결합기"] M2 --> COMBINE M3 --> COMBINE COMBINE --> TX["전송 매체<br/>(하나의 광대역 채널)"]

    각 신호가 서로 다른 반송파 주파수로 변조된 후 하나의 채널로 합쳐집니다.

    보호 대역(Guard Band)¶

    FDM에서 인접한 채널 간에는 반드시 보호 대역(Guard Band) 이 필요합니다. 보호 대역은 신호가 할당되지 않는 빈 주파수 구간입니다.

    왜 필요할까요? 실제 필터는 이상적이지 않기 때문에, 인접 채널의 신호가 약간씩 겹칠 수 있습니다. 보호 대역은 이러한 인접 채널 간섭(Adjacent Channel Interference) 을 방지하는 완충 지대 역할을 합니다.

    아래 표는 주파수 축 위에서 3개 채널이 보호 대역을 두고 배치된 예시입니다.

    구간 주파수 범위 역할
    채널 1 60 ~ 64 kHz 신호 1 전송
    보호 대역 64 ~ 68 kHz 간섭 방지 (빈 구간)
    채널 2 68 ~ 72 kHz 신호 2 전송
    보호 대역 72 ~ 76 kHz 간섭 방지 (빈 구간)
    채널 3 76 ~ 80 kHz 신호 3 전송

    보호 대역은 간섭을 줄여주지만, 그만큼 대역폭이 낭비되는 단점이 있습니다. 보호 대역을 최소화하면서도 간섭을 억제하는 것이 FDM 시스템 설계의 핵심 과제입니다.

    FDM의 대표적 활용 사례¶

    활용 분야 설명
    AM 라디오 방송 530~1700 kHz 대역을 10 kHz 간격으로 나누어 각 방송국에 할당합니다.
    FM 라디오 방송 88~108 MHz 대역을 200 kHz 간격으로 나누어 각 방송국에 할당합니다.
    아날로그 전화 시스템 음성 신호(0~4 kHz)를 12채널 단위로 묶어 그룹(Group), 슈퍼그룹(Supergroup) 등의 계위 구조를 형성합니다.
    CATV(케이블 TV) 동축 케이블의 넓은 대역폭을 6 MHz 간격으로 나누어 각 채널에 할당합니다.

    FDM 전화 시스템의 계위 구조¶

    FDM 기반 아날로그 전화 시스템은 국제적으로 표준화된 계위(Hierarchy) 구조를 사용합니다. 시험에서 자주 출제되는 내용이므로 정확히 정리하겠습니다.

    계위 구성 채널 수 주파수 대역
    채널(Channel) 음성 1회선 1 0~4 kHz
    그룹(Group) 12채널 12 60~108 kHz
    슈퍼그룹(Supergroup) 5그룹 60 312~552 kHz
    마스터그룹(Mastergroup) 10슈퍼그룹 600 564~3084 kHz
    슈퍼마스터그룹 3마스터그룹 1800 —

    기본 음성 채널 1개의 대역폭은 4 kHz이고, 12개를 모아 하나의 그룹(48 kHz 대역)을 구성합니다. 이 그룹 5개가 모여 슈퍼그룹(240 kHz 대역)이 됩니다.

    flowchart LR CH["음성 채널<br/>1회선<br/>(4 kHz)"] -->|"× 12"| GR["그룹<br/>12채널<br/>(48 kHz)"] GR -->|"× 5"| SG["슈퍼그룹<br/>60채널<br/>(240 kHz)"] SG -->|"× 10"| MG["마스터그룹<br/>600채널"]

    이 계위 구조를 통해 하나의 광대역 전송로에 수백~수천 개의 음성 통화를 동시에 실어 나를 수 있습니다.

    FDM의 장점과 단점¶

    구분 내용
    장점 구조가 단순하고 아날로그 신호에 직접 적용 가능합니다. 각 채널이 상시 사용 가능하여 지연이 없습니다.
    단점 보호 대역으로 인한 대역폭 낭비가 발생합니다. 채널 간 상호변조 잡음(Intermodulation Noise)이 발생할 수 있습니다. 사용자 수 변화에 유연하게 대응하기 어렵습니다.

    3️⃣ TDM — 시분할 다중화¶

    비유: 회전문과 카드 돌리기¶

    사무실 건물 입구에 회전문이 하나 있다고 가정하겠습니다. 한 번에 한 사람만 통과할 수 있지만, 회전문이 매우 빠르게 돌아가면서 차례대로 사람을 내보냅니다. 밖에서 보면 마치 여러 사람이 동시에 나오는 것처럼 보입니다.

    TDM도 같은 원리입니다. 하나의 채널을 매우 짧은 시간 단위로 나누고, 각 사용자에게 차례로 시간 슬롯을 배정합니다. 전환 속도가 충분히 빠르면, 각 사용자는 자신이 채널을 독점적으로 사용하고 있는 것처럼 느끼게 됩니다.

    정의¶

    TDM(Time Division Multiplexing, 시분할 다중화) 은 하나의 전송 채널의 전체 시간을 일정한 간격의 시간 슬롯(Time Slot) 으로 나누고, 각 슬롯에 서로 다른 신호의 데이터를 번갈아 배치하는 다중화 방식입니다.

    TDM의 동작 원리¶

    TDM에서는 각 입력 신호의 데이터를 샘플링하여 디지털화한 후, 정해진 순서에 따라 시간 슬롯에 배치합니다. 하나의 완전한 순환(채널 1 → 채널 2 → 채널 3 → … → 채널 1)을 프레임(Frame) 이라 합니다.

    sequenceDiagram participant S1 as 신호 1 participant S2 as 신호 2 participant S3 as 신호 3 participant MUX as 다중화기 participant CH as 전송 채널 Note over MUX,CH: 프레임 1 S1->>MUX: 데이터 a₁ MUX->>CH: 슬롯 1 (a₁) S2->>MUX: 데이터 b₁ MUX->>CH: 슬롯 2 (b₁) S3->>MUX: 데이터 c₁ MUX->>CH: 슬롯 3 (c₁) Note over MUX,CH: 프레임 2 S1->>MUX: 데이터 a₂ MUX->>CH: 슬롯 1 (a₂) S2->>MUX: 데이터 b₂ MUX->>CH: 슬롯 2 (b₂) S3->>MUX: 데이터 c₂ MUX->>CH: 슬롯 3 (c₂)

    프레임 안에서 각 신호가 자신의 슬롯에 차례로 데이터를 배치하는 구조입니다.

    동기식 TDM vs. 비동기식 TDM¶

    TDM은 시간 슬롯을 배정하는 방식에 따라 두 가지로 구분됩니다.

    구분 동기식 TDM (Synchronous TDM) 비동기식 TDM (Asynchronous TDM)
    슬롯 배정 각 채널에 고정된 슬롯을 미리 할당합니다 데이터가 있는 채널에만 슬롯을 동적으로 할당합니다
    빈 슬롯 해당 채널에 데이터가 없어도 빈 슬롯이 전송됩니다 데이터가 없으면 슬롯을 할당하지 않아 낭비가 없습니다
    효율 낭비 발생 가능 대역폭 활용 효율이 높습니다
    복잡도 구조가 단순합니다 주소 정보 등 부가 데이터가 필요하여 복잡합니다
    별칭 — 통계적 시분할 다중화(STDM) 라고도 합니다
    대표 적용 PCM 전화 시스템 (T1, E1 회선) 패킷 통신, ATM 등

    동기식 TDM은 마치 수업 시간표와 같습니다. 체육 시간에 비가 와서 수업이 취소되더라도, 그 시간은 비어 있습니다. 반면 비동기식 TDM은 빈 시간이 생기면 다른 수업이 바로 채워지는 유연한 시간표입니다.

    flowchart LR subgraph 동기식["동기식 TDM"] direction LR FS1["슬롯1<br/>(채널A)"] --- FS2["슬롯2<br/>(비어있음)"] --- FS3["슬롯3<br/>(채널C)"] --- FS4["슬롯4<br/>(채널D)"] end subgraph 비동기식["비동기식 TDM"] direction LR AS1["슬롯1<br/>(채널A+주소)"] --- AS2["슬롯2<br/>(채널C+주소)"] --- AS3["슬롯3<br/>(채널D+주소)"] end

    동기식에서는 채널 B에 데이터가 없어도 슬롯 2가 비어 있는 채로 전송됩니다. 비동기식에서는 채널 B의 빈 슬롯이 사라지고, 대신 각 슬롯에 주소 정보가 추가됩니다.

    TDM 전화 시스템의 계위 구조 (PCM 계위)¶

    TDM 기반 디지털 전화 시스템에서도 FDM과 마찬가지로 계위 구조가 존재합니다. 북미 방식(T-계열)과 유럽 방식(E-계열)이 있으며, 시험에서 자주 출제됩니다.

    북미 방식 (T-계열, DS 계위)

    계위 명칭 채널 수 전송 속도
    DS-0 기본 채널 1 64 kbps
    DS-1 (T1) 1차군 24 1.544 Mbps
    DS-2 (T2) 2차군 96 6.312 Mbps
    DS-3 (T3) 3차군 672 44.736 Mbps
    DS-4 (T4) 4차군 4032 274.176 Mbps

    유럽 방식 (E-계열, CEPT 계위)

    계위 명칭 채널 수 전송 속도
    E-0 기본 채널 1 64 kbps
    E-1 1차군 30 2.048 Mbps
    E-2 2차군 120 8.448 Mbps
    E-3 3차군 480 34.368 Mbps
    E-4 4차군 1920 139.264 Mbps

    한국은 유럽 방식(E-계열)을 채택하고 있습니다. 기본 단위인 DS-0(E-0)의 64 kbps는 음성 1채널을 PCM으로 디지털화한 결과입니다(8 kHz 샘플링 × 8 bit = 64 kbps). 이전 차시에서 학습한 PCM 원리가 여기에 직접 연결됩니다.

    계산 확인: E-1의 전송 속도 = 32 타임슬롯 × 8 bit × 8000 프레임/초 = 2,048,000 bps = 2.048 Mbps (30채널은 음성용이고, 나머지 2슬롯은 동기화 및 시그널링용입니다.)

    TDM의 장점과 단점¶

    구분 내용
    장점 디지털 신호에 적합하며, 보호 대역이 필요 없어 대역폭 효율이 높습니다. 상호변조 잡음이 발생하지 않습니다. 현대 디지털 통신의 기본 방식입니다.
    단점 정밀한 동기화(Synchronization)가 필수입니다. 동기식 TDM에서는 빈 슬롯으로 인한 낭비가 발생할 수 있습니다.

    4️⃣ FDM vs. TDM 종합 비교¶

    이 비교표는 시험에서 자주 출제되는 핵심 내용입니다. 반드시 정리해 두시기 바랍니다.

    비교 항목 FDM (주파수 분할) TDM (시분할)
    분할 기준 주파수(Frequency) 시간(Time)
    신호 유형 주로 아날로그 신호 주로 디지털 신호
    채널 사용 방식 각 채널이 좁은 대역폭을 상시 점유 각 채널이 전체 대역폭을 순간적으로 점유
    보호 구간 보호 대역(Guard Band) 필요 보호 시간(Guard Time) 필요
    간섭 유형 상호변조 잡음(Intermodulation Noise) 누화(Crosstalk), 동기 오류
    대역폭 낭비 보호 대역에 의한 낭비 빈 슬롯에 의한 낭비(동기식)
    대표 적용 AM/FM 라디오, 케이블TV, 아날로그 전화 PCM 전화(T1/E1), 디지털 통신
    동기화 요구 낮음 높음 (정밀 동기 필수)

    아래 다이어그램은 FDM과 TDM의 자원 분배 방식을 개념적으로 비교합니다.

    flowchart TD subgraph FDM["FDM: 주파수 축으로 분할"] direction LR F1["채널 1<br/>f₁ 대역"] ~~~ F2["채널 2<br/>f₂ 대역"] ~~~ F3["채널 3<br/>f₃ 대역"] end subgraph TDM["TDM: 시간 축으로 분할"] direction LR T1["슬롯 1<br/>(채널 1)"] ~~~ T2["슬롯 2<br/>(채널 2)"] ~~~ T3["슬롯 3<br/>(채널 3)"] end
    • FDM은 주파수 축을 나눕니다. 각 채널은 자신의 주파수 대역에서 항상 데이터를 보냅니다.
    • TDM은 시간 축을 나눕니다. 각 채널은 자신의 시간 슬롯에서 전체 대역폭을 사용하여 데이터를 보냅니다.

    이 차이를 "주파수-시간 격자"로 시각화하면 더욱 명확합니다.

    왼쪽(FDM)에서는 주파수 축을 나누어 각 채널이 좁은 대역을 상시 점유합니다. 오른쪽(TDM)에서는 시간 축을 나누어 각 채널이 전체 대역폭을 순간적으로 사용합니다.

    ⚠️ 자주 하는 실수와 주의할 점¶

    실수 유형 올바른 이해
    "FDM은 아날로그에만 쓰인다" FDM은 아날로그 신호에 주로 사용되지만, OFDM처럼 디지털 시스템에도 활용됩니다.
    "TDM은 동시 전송이 아니다" 물리적으로는 번갈아 전송하지만, 속도가 충분히 빠르면 사용자 관점에서는 사실상 동시 전송입니다.
    "보호 대역과 보호 시간을 혼동" FDM의 보호 대역은 주파수 영역의 빈 구간이고, TDM의 보호 시간은 시간 영역의 빈 구간입니다.
    "E-1의 채널 수를 32로 답한다" E-1은 32개의 타임슬롯을 가지지만, 실제 음성 채널은 30개입니다(나머지 2개는 동기화·시그널링용).
    "T1과 E1의 채널 수를 혼동" T1(DS-1)은 24채널, E-1은 30채널입니다. 한국은 E-계열을 사용합니다.

    🔧 따라하기 실습 — FDM·TDM 배분표 설계¶

    다음 조건에서 FDM 배분표와 TDM 배분표를 직접 작성하는 실습을 진행하겠습니다.

    실습 조건¶

    • 사용자: A, B, C, D (4명)
    • 각 사용자의 음성 신호 대역폭: 4 kHz
    • 전체 전송 매체 대역폭: 40 kHz
    • 보호 대역: 2 kHz (FDM의 경우)
    • 프레임 주기: 125 μs (TDM의 경우)

    📋 Step 1: FDM 배분표 작성¶

    전체 40 kHz를 4명에게 배분합니다. 각 채널은 4 kHz이고, 채널 사이에 2 kHz 보호 대역을 둡니다.

    아래 빈 칸을 채워 보시기 바랍니다.

    구간 주파수 범위 역할
    채널 A 0 ~ 4 kHz 사용자 A
    보호 대역 4 ~ 6 kHz 간섭 방지
    채널 B ( ) 사용자 B
    보호 대역 ( ) 간섭 방지
    채널 C ( ) 사용자 C
    보호 대역 ( ) 간섭 방지
    채널 D ( ) 사용자 D
    정답 확인 | 구간 | 주파수 범위 | 역할 | |------|-------------|------| | 채널 A | 0 ~ 4 kHz | 사용자 A | | 보호 대역 | 4 ~ 6 kHz | 간섭 방지 | | 채널 B | **6 ~ 10 kHz** | 사용자 B | | 보호 대역 | **10 ~ 12 kHz** | 간섭 방지 | | 채널 C | **12 ~ 16 kHz** | 사용자 C | | 보호 대역 | **16 ~ 18 kHz** | 간섭 방지 | | 채널 D | **18 ~ 22 kHz** | 사용자 D | 총 사용 대역: 4채널 × 4 kHz + 3개 보호 대역 × 2 kHz = **22 kHz** 잔여 대역: 40 - 22 = **18 kHz** (미사용) 보호 대역으로 인해 전체 대역의 약 **27%**(6/22)가 실제 신호 전송에 사용되지 않습니다.

    📋 Step 2: TDM 배분표 작성¶

    프레임 주기 125 μs를 4명에게 균등 배분합니다.

    각 사용자의 시간 슬롯 길이를 계산하시기 바랍니다.

    정답 확인 125 μs ÷ 4 = **31.25 μs/슬롯** | 슬롯 | 시간 범위 | 할당 사용자 | 사용 대역폭 | |------|-----------|-------------|-------------| | 슬롯 1 | 0 ~ 31.25 μs | 사용자 A | 전체 40 kHz | | 슬롯 2 | 31.25 ~ 62.50 μs | 사용자 B | 전체 40 kHz | | 슬롯 3 | 62.50 ~ 93.75 μs | 사용자 C | 전체 40 kHz | | 슬롯 4 | 93.75 ~ 125.00 μs | 사용자 D | 전체 40 kHz | TDM에서는 보호 대역이 없으며, 각 사용자가 자신의 시간 슬롯에서 **전체 대역폭**을 사용합니다.

    📋 Step 3: 효율 비교¶

    위 결과를 바탕으로 두 방식의 대역폭 활용 효율을 비교하시기 바랍니다.

    정답 확인 | 항목 | FDM | TDM | |------|-----|-----| | 실제 신호 전송에 사용되는 대역폭 | 16 kHz (4 × 4) | 40 kHz (전체) | | 보호 구간에 소모되는 자원 | 6 kHz (보호 대역) | 없음 (보호 시간은 극히 짧음) | | 대역폭 활용률 | 16/22 ≈ **72.7%** | **100%** (이론적) | 다만 TDM에서는 사용자에게 데이터가 없는 시간에도 슬롯이 할당(동기식)되는 낭비가 있을 수 있습니다.

    📋 Step 4: 만약 사용자 B가 데이터를 보내지 않는다면?¶

    동기식 TDM과 비동기식 TDM에서 각각 어떤 차이가 발생하는지 생각하시기 바랍니다.

    정답 확인 - **동기식 TDM**: 슬롯 2는 비어 있는 채로 그대로 전송됩니다. 대역폭의 25%가 낭비됩니다. - **비동기식 TDM**: 슬롯 2가 사라지고, 사용자 A, C, D의 데이터만 담긴 3개의 슬롯이 전송됩니다. 대역폭 낭비가 없지만, 각 슬롯에 "이 데이터가 어느 사용자의 것인지"를 알려주는 **주소 정보**가 추가됩니다.

    📋 Step 5: 핵심 정리 직접 작성¶

    아래 빈 칸을 채워 FDM과 TDM의 핵심 차이를 한 문장으로 정리하시기 바랍니다.

    "FDM은 _ 축을 나누고, TDM은 _ 축을 나눈다."

    "FDM에서 간섭 방지를 위해 필요한 것은 __이고, TDM에서 정상 동작을 위해 필수적인 것은 ____이다."

    정답 확인 > "FDM은 **주파수** 축을 나누고, TDM은 **시간** 축을 나눈다." > "FDM에서 간섭 방지를 위해 필요한 것은 **보호 대역(Guard Band)**이고, TDM에서 정상 동작을 위해 필수적인 것은 **동기화(Synchronization)**이다."

    📝 형성 평가¶

    객관식¶

    1. 다중화(Multiplexing)의 주된 목적으로 가장 적절한 것은 무엇입니까?

    ① 신호의 품질을 높이기 위해 여러 채널로 동시에 전송하는 것 ② 하나의 전송 매체를 여러 사용자가 공유하여 효율적으로 사용하는 것 ③ 전송 속도를 낮추어 오류 발생 확률을 줄이는 것 ④ 아날로그 신호를 디지털 신호로 변환하는 것

    정답 확인 **정답: ②** 다중화는 하나의 전송 매체(고속·광대역 채널)를 여러 사용자의 신호가 공유할 수 있도록 분할하는 기술입니다. 경제성과 대역폭 활용 효율 향상이 핵심 목적입니다.

    2. FDM(주파수 분할 다중화)에서 인접 채널 사이에 보호 대역(Guard Band)을 두는 가장 주된 이유는 무엇입니까?

    ① 전체 대역폭을 증가시키기 위해 ② 각 채널의 전송 속도를 높이기 위해 ③ 인접 채널 간의 간섭을 방지하기 위해 ④ 디지털 신호의 동기화를 맞추기 위해

    정답 확인 **정답: ③** 실제 대역 통과 필터(BPF)는 이상적이지 않아 인접 주파수 대역의 신호가 누출될 수 있습니다. 보호 대역은 이러한 인접 채널 간섭(Adjacent Channel Interference)을 방지하는 완충 구간입니다.

    3. 유럽 방식(E-계열) TDM 전화 시스템에서 E-1 회선의 음성 채널 수와 전송 속도가 올바르게 짝지어진 것은 무엇입니까?

    ① 24채널, 1.544 Mbps ② 30채널, 2.048 Mbps ③ 32채널, 2.048 Mbps ④ 30채널, 1.544 Mbps

    정답 확인 **정답: ②** E-1은 총 32개의 타임슬롯을 가지지만, 음성 전송에 사용되는 채널은 **30개**입니다(슬롯 0은 동기화, 슬롯 16은 시그널링). 전송 속도는 32 × 64 kbps = **2.048 Mbps**입니다. ①은 북미 방식(T1)의 사양이고, ③은 전체 타임슬롯 수를 채널 수로 혼동한 오답입니다.

    서술형¶

    4. FDM과 TDM의 자원 분배 방식 차이를 "주파수 축"과 "시간 축"이라는 관점에서 비교하여 설명하고, 각 방식이 적합한 응용 분야를 한 가지씩 서술하시기 바랍니다.

    정답 예시 **FDM**은 전송 매체의 전체 **주파수 대역을 여러 개의 좁은 대역으로 나누어** 각 사용자에게 할당합니다. 각 사용자는 자신의 주파수 대역에서 상시 데이터를 전송할 수 있으며, 대역 간 간섭을 방지하기 위해 보호 대역이 필요합니다. AM/FM 라디오 방송이 대표적인 FDM 활용 사례입니다.
