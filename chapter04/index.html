    4차시: 실습 체험 — 신호 읽기와 기초 개념 확인 문제 풀이¶

    ⏰ 50분 · 파형 읽기 · 대역폭 문제 풀이 · Part 1 핵심 정리 · 난이도 ●●●○○

    학습목표: 파형 그래프에서 주파수·진폭·위상 값을 읽어내고, 대역폭 관련 기출 유형 문제의 오답 함정을 식별할 수 있습니다.

    오늘의 질문: "시험지 위의 파형 그래프를 보았을 때, 30초 안에 주파수·진폭·위상을 정확히 읽어낼 수 있습니까?"

    📋 학습 목표¶

    • 주파수·진폭·위상 정보를 담은 파형 그래프를 보고 각 특성값을 읽어낼 수 있다.
    • 대역폭 관련 기출 유형 문제를 분석하고 오답 함정 포인트를 식별할 수 있다.
    • Part 1에서 학습한 핵심 용어를 자신의 언어로 정리하여 설명할 수 있다.

    🎯 핵심 주제 카드¶

    🔬 파형 읽기 실습¶

    파형 그래프에서 주파수, 진폭, 위상을 수치로 추출하는 5단계 절차를 익힙니다.

    📝 기출 유형 문제 풀이¶

    대역폭·스펙트럼 관련 5지선다형 문제를 풀고, 자주 출제되는 오답 함정을 분석합니다.

    ⏱️ 수업 흐름¶

    🔄 1단계: 복습 워밍업 (5분)¶

    1~3차시 핵심 개념을 빠르게 점검합니다. 주파수·진폭·위상·대역폭의 정의를 한 문장으로 떠올리는 연습을 합니다.

    📊 2단계: 파형 읽기 절차 학습 (15분)¶

    파형 그래프에서 수치를 추출하는 5단계 절차를 배우고, 세 가지 연습 파형에 직접 적용합니다.

    🧩 3단계: 기출 유형 문제 풀이 (15분)¶

    대역폭과 스펙트럼 관련 5지선다형 문제를 풀면서 오답 함정 패턴을 식별합니다.

    📦 4단계: Part 1 핵심 총정리 (10분)¶

    Part 1 전체(1~4차시)에서 다룬 핵심 용어와 공식을 하나의 정리표로 완성합니다.

    ✅ 5단계: 형성 평가 및 성찰 (5분)¶

    확인 문제를 풀고, 자기점검 체크리스트를 통해 학습 달성도를 확인합니다.

    왜 이걸 배우나요?¶

    1~3차시에서 주파수, 진폭, 위상, 대역폭, 스펙트럼이라는 핵심 개념을 학습했습니다. 그런데 개념을 "아는 것"과 시험 문제에서 "정확히 적용하는 것"은 전혀 다른 역량입니다.

    공공기관 통신이론 시험에서는 파형 그래프를 제시하고 특성값을 묻는 문제가 자주 출제됩니다. 그래프를 읽는 체계적인 절차를 갖추지 않으면, 단위 실수나 축 해석 오류로 점수를 잃게 됩니다. 이번 차시는 그 실수를 줄이기 위한 훈련 시간입니다.

    또한 Part 1의 마지막 차시인 만큼, 지금까지 배운 내용을 하나의 틀로 엮어 정리하겠습니다. 이 틀이 Part 2(변조와 복조)의 기반이 됩니다.

    📚 1단계: 복습 워밍업 — 핵심 개념 한눈에 보기¶

    본격적인 실습에 앞서, 1~3차시에서 배운 핵심 용어를 간략히 되짚겠습니다. 아래 표를 보면서 각 용어의 정의를 자신의 말로 떠올려 보시기 바랍니다.

    용어 한 줄 정의 단위 일상 비유
    주파수 (Frequency) 1초 동안 파형이 반복되는 횟수 Hz (헤르츠) 줄넘기를 1초에 몇 번 돌리는지
    주기 (Period) 파형 한 번이 완성되는 데 걸리는 시간 s (초) 줄넘기 한 바퀴에 걸리는 시간
    진폭 (Amplitude) 파형의 최대 높이(중심선 기준) V, A 등 그네를 최대로 밀었을 때의 높이
    위상 (Phase) 파형의 시작 위치(기준 시점 대비 어긋남) ° (도) 또는 rad 달리기에서 출발선이 얼마나 앞/뒤인지
    대역폭 (Bandwidth) 신호가 차지하는 주파수 범위의 폭 Hz 도로의 차선 수(넓을수록 많은 차가 지남)
    스펙트럼 (Spectrum) 신호를 주파수별 성분으로 분해한 그림 — 프리즘에 빛을 통과시켰을 때 나타나는 무지개

    주파수와 주기의 관계는 가장 기본적인 공식입니다:

    $$f = \frac{1}{T} \quad \Longleftrightarrow \quad T = \frac{1}{f}$$

    이 관계는 이번 차시 파형 읽기 실습에서 반복적으로 사용됩니다.

    아래 다이어그램은 1~3차시에서 다룬 개념들의 연결 관계를 정리한 것입니다.

    mindmap root((통신 신호<br/>기초 개념)) 시간 영역 주파수 주기 진폭 위상 주파수 영역 스펙트럼 대역폭 관계식 "f = 1/T" "BW = f_H - f_L"

    📚 2단계: 파형 읽기 실습 — 5단계 절차¶

    🔎 파형 읽기가 중요한 이유¶

    시험 문제에서 파형 그래프가 주어지면, 여러분은 제한된 시간 안에 수치를 정확히 추출해야 합니다. 감으로 읽는 것이 아니라, 정해진 절차를 따르면 실수를 크게 줄일 수 있습니다.

    라디오의 음량 조절기와 채널 선택기를 생각해 보겠습니다. 음량 조절기를 돌리면 진폭이 바뀌고, 채널 선택기를 돌리면 주파수가 바뀝니다. 파형 그래프에서 이 두 가지 정보(그리고 위상까지)를 정확히 읽어내는 것이 이번 실습의 핵심입니다.

    📋 5단계 파형 읽기 절차¶

    아래 절차를 순서대로 따르면, 어떤 정현파(사인파) 그래프가 주어지더라도 체계적으로 값을 추출할 수 있습니다.

    flowchart TD S1["1단계<br/>축 확인"] --> S2["2단계<br/>진폭 읽기"] S2 --> S3["3단계<br/>주기 읽기"] S3 --> S4["4단계<br/>주파수 계산"] S4 --> S5["5단계<br/>위상 확인"]

    ✏️ 1단계: 축 확인 — "단위부터 봅니다"¶

    파형 그래프를 받으면, 가장 먼저 가로축과 세로축의 라벨과 단위를 확인합니다.

    확인 항목 가로축(시간 축) 세로축(전압/전류 축)
    라벨 t(시간) v(t), i(t) 등
    단위 s, ms, μs V, mV, A, mA
    눈금 간격 한 칸이 몇 초인지 한 칸이 몇 V인지

    주의할 점: 시험 문제에서 가로축 단위가 ms(밀리초)인 경우가 매우 흔합니다. ms를 s로 변환하지 않으면 주파수 계산에서 1000배 차이가 발생합니다.

    단위 환산 핵심 - 1 ms = 0.001 s = 10⁻³ s - 1 μs = 0.000001 s = 10⁻⁶ s - 1 kHz = 1,000 Hz = 10³ Hz - 1 MHz = 1,000,000 Hz = 10⁶ Hz

    ✏️ 2단계: 진폭 읽기 — "꼭대기에서 중심선까지"¶

    진폭(Amplitude)은 파형의 중심선(보통 0 V)에서 최대 꼭대기까지의 거리입니다.

    용어 의미 기호
    최대 진폭 (Peak Amplitude) 중심선 → 꼭대기 A, V_p
    피크-투-피크 (Peak-to-Peak) 최저점 → 최고점 (전체 폭) V_pp

    관계식: V_pp = 2 × V_p

    읽기 방법:

    1. 세로축에서 파형의 최고점 값을 읽습니다. (예: +3 V)
    2. 파형의 최저점 값을 읽습니다. (예: -3 V)
    3. 최대 진폭 = 최고점 값 = 3 V (중심이 0 V인 경우)
    4. V_pp = 최고점 - 최저점 = 3 - (-3) = 6 V

    시험 함정: 문제가 "진폭"을 물으면 V_p(3 V)를, "피크-투-피크 전압"을 물으면 V_pp(6 V)를 답해야 합니다. 이 차이를 혼동하면 오답이 됩니다.

    ✏️ 3단계: 주기 읽기 — "같은 모양이 반복되는 간격"¶

    주기(Period, T)는 파형이 한 번 완전히 반복되는 데 걸리는 시간입니다.

    읽기 방법:

    1. 파형에서 같은 위치·같은 방향의 두 점을 찾습니다.
    2. 예: 양(+)의 방향으로 중심선을 처음 지나는 점 → 다음 번 같은 방식으로 지나는 점
    3. 두 점 사이의 가로축 거리를 읽습니다. 그것이 주기 T입니다.
    측정 기준점 설명 정확도
    양(+) 방향 영점 교차 0 V를 아래→위로 지나는 점 높음 (교차점이 명확)
    꼭대기(최고점) 최대값 위치 보통 (정확한 피크 찾기 어려울 수 있음)
    골(최저점) 최소값 위치 보통

    가장 정확한 방법은 영점 교차(zero crossing) 지점을 기준으로 측정하는 것입니다. 꼭대기는 완만한 곡선이라 정확한 위치를 집어내기 어렵지만, 영점 교차는 기울기가 가장 급해서 위치가 명확합니다.

    ✏️ 4단계: 주파수 계산 — "주기의 역수"¶

    주기 T를 읽었으면 주파수는 바로 계산됩니다:

    $$f = \frac{1}{T}$$

    실전 예시:

    상황 주기 T 주파수 f 계산 결과
    예시 A 4 ms f = 1 / 0.004 s 250 Hz
    예시 B 20 μs f = 1 / 0.00002 s 50 kHz
    예시 C 0.5 ms f = 1 / 0.0005 s 2 kHz

    계산 팁: ms 단위일 때 빠른 계산법이 있습니다.

    $$T \text{(ms)} \to f = \frac{1000}{T\text{(ms 숫자)}} \text{ Hz}$$

    예를 들어 T = 4 ms이면, f = 1000 / 4 = 250 Hz입니다.

    마찬가지로 μs 단위에서는:

    $$T \text{(μs)} \to f = \frac{1{,}000{,}000}{T\text{(μs 숫자)}} \text{ Hz} = \frac{1000}{T\text{(μs 숫자)}} \text{ kHz}$$

    ✏️ 5단계: 위상 확인 — "기준보다 얼마나 앞서거나 뒤처져 있는가"¶

    위상(Phase, φ)은 기준 신호(보통 sin 파형의 t=0 시작)에 비해 파형이 시간축에서 얼마나 이동했는지를 나타냅니다.

    읽기 방법:

    1. 기준 정현파: sin(2πft)는 t=0에서 값이 0이고, 양(+)의 방향으로 출발합니다.
    2. 주어진 파형이 t=0에서 이미 양의 값을 가지면 → 위상이 앞서 있습니다 (leading, +φ)
    3. 주어진 파형이 t=0에서 음의 값을 가지면 → 위상이 뒤처져 있습니다 (lagging, -φ)

    위상 이동량 계산:

    파형이 시간축에서 Δt만큼 이동했다면:

    $$\phi = \frac{\Delta t}{T} \times 360°$$

    상황 T Δt (앞으로 이동) 위상 φ
    예시 A 4 ms 1 ms (1/4) × 360° = 90° (leading)
    예시 B 10 ms 2.5 ms (2.5/10) × 360° = 90° (leading)
    예시 C 8 ms 2 ms (2/8) × 360° = 90° (leading)

    이 세 예시가 모두 90°인 이유는, 이동량이 정확히 주기의 1/4이기 때문입니다. 시험에서 자주 나오는 위상값은 0°, 45°, 90°, 180°, 270°입니다.

    📌 파형 읽기 — 실수하기 쉬운 3가지 함정¶

    함정 유형 설명 방지법
    단위 미변환 ms를 s로 바꾸지 않고 주파수 계산 축 단위 확인을 1단계로 무조건 실행
    V_p와 V_pp 혼동 진폭을 묻는데 V_pp를 답함 (또는 반대) 문제가 "진폭"인지 "피크-투-피크"인지 밑줄 긋기
    반주기를 주기로 오인 꼭대기→골 간격을 주기로 읽음 반드시 같은 위치·같은 방향 두 점의 간격을 측정

    이 세 가지는 실제 시험에서 가장 빈번하게 발생하는 실수입니다. 특히 세 번째 함정은 매우 흔합니다. 꼭대기에서 다음 골까지의 거리는 반 주기(T/2)입니다. 이것을 주기로 오인하면 주파수가 2배로 계산됩니다.

    📚 3단계: 기출 유형 문제 풀이 — 대역폭과 스펙트럼¶

    대역폭 핵심 공식 재확인¶

    대역폭(BW)은 신호가 차지하는 주파수 범위의 폭입니다.

    $$BW = f_H - f_L$$

    여기서 f_H는 신호의 최고 주파수, f_L은 최저 주파수입니다.

    flowchart LR A["최저 주파수<br/>f_L"] -->|"대역폭 BW"| B["최고 주파수<br/>f_H"]

    예시: 음성 신호의 주파수 범위가 300 Hz ~ 3,400 Hz라면

    $$BW = 3{,}400 - 300 = 3{,}100 \text{ Hz} \approx 3.1 \text{ kHz}$$

    기출 유형별 오답 함정 분석¶

    시험에서 대역폭 관련 문제는 몇 가지 정형화된 패턴으로 출제됩니다. 각 유형의 함정이 어디에 있는지를 미리 파악하면 정답률을 크게 높일 수 있습니다.

    🔹 유형 1: 직접 계산형

    문제 예시: 어떤 신호의 주파수 성분이 2 kHz에서 10 kHz까지 분포한다. 이 신호의 대역폭은?

    ① 2 kHz   ② 8 kHz   ③ 10 kHz   ④ 12 kHz   ⑤ 5 kHz

    풀이 및 함정 분석 **정답: ② 8 kHz** BW = 10 - 2 = 8 kHz **함정 분석**: - ① 2 kHz → f_L 값을 그대로 답한 경우 - ③ 10 kHz → f_H 값을 그대로 답한 경우 (대역폭과 최고 주파수를 혼동) - ④ 12 kHz → f_H + f_L을 계산한 경우 (뺄셈이 아니라 덧셈을 한 실수) - ⑤ 5 kHz → 중심 주파수를 계산한 경우 이 유형에서 가장 흔한 함정은 **③번**, 즉 f_H 자체를 대역폭으로 답하는 것입니다. 특히 f_L = 0인 경우(기저대역 신호)에는 BW = f_H가 되어 맞지만, f_L ≠ 0인 경우에는 반드시 빼야 합니다.

    🔹 유형 2: 단위 변환 함정형

    문제 예시: FM 방송 신호의 주파수 범위가 88 MHz에서 108 MHz이다. 전체 FM 방송 대역의 대역폭은?

    ① 20 Hz   ② 20 kHz   ③ 20 MHz   ④ 108 MHz   ⑤ 196 MHz

    풀이 및 함정 분석 **정답: ③ 20 MHz** BW = 108 - 88 = 20 MHz **함정 분석**: - ① 20 Hz → 숫자 20은 맞지만 단위를 Hz로 착각 - ② 20 kHz → 숫자 20은 맞지만 단위를 kHz로 착각 - ④ 108 MHz → f_H를 대역폭으로 혼동 - ⑤ 196 MHz → f_H + f_L 계산 이 유형의 핵심은 **계산 자체는 단순**하지만, 보기의 단위가 다르게 제시되어 혼동을 유발한다는 점입니다. 계산 결과의 단위를 보기와 꼼꼼히 대조해야 합니다.

    🔹 유형 3: 개념 구분형 (대역폭 vs 스펙트럼 vs 주파수)

    문제 예시: 다음 중 대역폭(Bandwidth)에 대한 설명으로 옳지 않은 것은?

    ① 신호가 점유하는 주파수 범위의 폭이다. ② 대역폭이 넓을수록 더 많은 정보를 전송할 수 있다. ③ 대역폭의 단위는 Hz이다. ④ 대역폭은 신호의 최고 주파수와 동일하다. ⑤ 대역폭이 넓은 채널은 고속 데이터 전송에 유리하다.

    풀이 및 함정 분석 **정답: ④** 대역폭은 f_H - f_L이므로, 최저 주파수가 0이 아닌 한 최고 주파수와 동일하지 않습니다. ④번은 **기저대역(baseband) 신호에서만 성립**하는 특수한 경우를 일반적인 정의처럼 서술한 오답입니다. **함정 분석**: - 이 유형에서는 "옳지 않은 것"을 고르라는 부정 문제임을 놓치면 안 됩니다. ①②③⑤는 모두 올바른 설명입니다. - ④번이 함정인 이유: 기저대역에서는 f_L = 0이므로 BW = f_H가 맞습니다. 하지만 통과대역(bandpass) 신호에서는 성립하지 않습니다. 시험에서는 "항상 동일하다"는 표현이 오답 신호인 경우가 많습니다.

    🔹 유형 4: 중심 주파수와 대역폭의 관계형

    문제 예시: 어떤 대역통과 필터의 중심 주파수가 100 kHz이고 대역폭이 10 kHz이다. 이 필터가 통과시키는 주파수 범위는?

    ① 90 kHz ~ 100 kHz   ② 95 kHz ~ 105 kHz   ③ 100 kHz ~ 110 kHz   ④ 90 kHz ~ 110 kHz   ⑤ 50 kHz ~ 150 kHz

    풀이 및 함정 분석 **정답: ② 95 kHz ~ 105 kHz** **중심 주파수(f_c)**를 기준으로 대역폭이 양쪽으로 균등하게 분포한다고 가정하면: - f_L = f_c - BW/2 = 100 - 5 = **95 kHz** - f_H = f_c + BW/2 = 100 + 5 = **105 kHz** **함정 분석**: - ① → 중심 주파수 아래쪽으로만 대역폭을 적용한 경우 - ③ → 중심 주파수 위쪽으로만 대역폭을 적용한 경우 - ④ → 대역폭 10 kHz를 양쪽에 각각 10 kHz씩 적용한 경우 (BW를 2로 나누지 않음) - ⑤ → BW를 50 kHz로 잘못 계산한 경우 핵심 공식: $$f_L = f_c - \frac{BW}{2}, \quad f_H = f_c + \frac{BW}{2}$$

    오답 함정 패턴 종합 정리¶

    기출 문제에서 반복적으로 등장하는 오답 함정 패턴을 정리하면 다음과 같습니다.

    함정 패턴 설명 빈출 보기 유형
    f_H 자체를 BW로 혼동 BW = f_H - f_L인데 f_L을 빼지 않음 f_H 값이 보기에 포함
    덧셈 실수 f_H - f_L 대신 f_H + f_L을 계산 합산값이 보기에 포함
    단위 불일치 계산은 맞으나 단위 변환 실수 같은 숫자에 다른 단위
    BW/2 미적용 중심 주파수 문제에서 대역폭을 반으로 나누지 않음 범위가 2배로 확장된 보기
    부정 문제 간과 "옳지 않은 것"을 물었는데 옳은 것을 고름 부정어(않은, 아닌) 존재

    차시 핵심 용어 정의 공식/관계 단위

    3차시 스펙트럼 신호를 주파수 성분별로 분해한 표현 — —
    3차시 대역폭(BW) 신호가 차지하는 주파수 범위의 폭 BW = f_H - f_L Hz
    3차시 중심 주파수(f_c) 대역의 중앙에 위치하는 주파수 f_c = (f_H + f_L) / 2 Hz
    4차시 V_pp 피크-투-피크 전압 (최고-최저 간 전압차) V_pp = 2 × V_p V

    📦 Part 1 핵심 공식 모음¶

    공식 의미 적용 상황
    $f = \frac{1}{T}$ 주파수-주기 관계 파형에서 주기를 읽고 주파수를 구할 때
    $BW = f_H - f_L$ 대역폭 계산 주파수 범위에서 대역폭을 구할 때
    $f_c = \frac{f_H + f_L}{2}$ 중심 주파수 대역의 중앙 주파수를 구할 때
    $f_L = f_c - \frac{BW}{2}$ 최저 주파수 중심 주파수와 대역폭으로 범위를 구할 때
    $f_H = f_c + \frac{BW}{2}$ 최고 주파수 상동
    $\phi = \frac{\Delta t}{T} \times 360°$ 위상 계산 시간 이동량에서 위상을 구할 때
    $V_{pp} = 2 \times V_p$ 진폭-피크투피크 관계 진폭값에서 전체 전압 폭을 구할 때

    객관식 1. 어떤 정현파의 주기가 0.5 ms일 때, 주파수는 얼마입니까?

    ① 500 Hz   ② 2 kHz   ③ 5 kHz   ④ 200 Hz   ⑤ 20 kHz

    정답 확인 **정답: ② 2 kHz** f = 1/T = 1 / 0.0005 s = 2,000 Hz = 2 kHz 빠른 계산법: T = 0.5 ms이므로 f = 1000 / 0.5 = 2,000 Hz = 2 kHz **오답 분석**: - ① 500 Hz: T를 2 ms로 잘못 읽은 경우 - ③ 5 kHz: T를 0.2 ms로 잘못 계산한 경우 - ④ 200 Hz: T를 5 ms로 혼동한 경우 - ⑤ 20 kHz: T를 0.05 ms로 혼동한 경우

    객관식 2. 어떤 대역통과 필터의 통과 주파수 범위가 450 kHz ~ 470 kHz이다. 이 필터의 대역폭과 중심 주파수를 올바르게 짝지은 것은?

    보기 대역폭 중심 주파수
    ① 20 kHz 470 kHz
    ② 20 kHz 460 kHz
    ③ 920 kHz 460 kHz
    ④ 10 kHz 460 kHz
    ⑤ 20 kHz 450 kHz
    정답 확인 **정답: ②** - BW = 470 - 450 = **20 kHz** - f_c = (470 + 450) / 2 = 920 / 2 = **460 kHz** **오답 분석**: - ① 중심 주파수를 f_H로 혼동 - ③ 대역폭을 f_H + f_L로 계산한 실수 - ④ 대역폭을 BW/2로 잘못 계산 - ⑤ 중심 주파수를 f_L로 혼동

    객관식 3. 어떤 정현파가 t = 0에서 최고점(양의 최대값)에 위치한다. 이 신호를 sin 함수로 표현할 때, 위상은 얼마입니까?

    ① 0°   ② +45°   ③ +90°   ④ +180°   ⑤ -90°

    정답 확인 **정답: ③ +90°** sin(2πft + 90°) = cos(2πft)입니다. cos 함수는 t = 0에서 최대값을 가집니다. 따라서 t = 0에서 최고점에 있는 정현파를 sin 함수로 표현하면 위상이 +90°입니다. **오답 분석**: - ① 0°: 기준 sin파는 t = 0에서 0 V이므로 최고점이 아닙니다 - ② +45°: sin(45°) = 0.707로, 최대값이 아닙니다 - ④ +180°: sin(180°) = 0으로, t = 0에서 0 V가 됩니다 - ⑤ -90°: sin(-90°) = -1로, 최저점이 됩니다

    서술형 1. 아래 조건의 정현파에 대해 (1) 진폭, (2) 주기, (3) 주파수, (4) 위상, (5) 대역폭을 모두 구하시기 바랍니다. 풀이 과정을 포함하여 작성하십시오.

    조건: 세로축 범위 -4 V ~ +4 V, 가로축 단위 ms, 양 방향 영점 교차 간격 = 8 ms, t = 0에서 0 V(양 방향 출발). 이 신호는 단일 주파수 성분만 가진 순수 정현파입니다.

    정답 확인 **(1) 진폭**: 최고점 = +4 V, 최저점 = -4 V → V_p = **4 V** (V_pp = 8 V) **(2) 주기**: 양 방향 영점 교차 간격 = **8 ms** **(3) 주파수**: f = 1000 / 8 = **125 Hz** **(4) 위상**: t = 0에서 0 V이며 양(+) 방향으로 출발 → 기준 sin파와 동일한 시작 → **φ = 0°** **(5) 대역폭**: 단일 주파수 성분만 가진 순수 정현파이므로, 이론적으로 대역폭은 **0 Hz**입니다. (순수 정현파는 하나의 주파수에만 에너지가 존재하므로 f_H = f_L, BW = 0) **채점 기준**: - (1)~(3) 각 1점, (4) 1점, (5) 2점 (대역폭이 0 Hz인 이유를 설명하면 가산) - 단위를 정확히 기재했는지 확인

    ✅ 자기점검 체크리스트¶

    • 파형 그래프에서 5단계 절차(축 확인 → 진폭 → 주기 → 주파수 → 위상)를 순서대로 적용하여 수치를 추출할 수 있습니다.
    • V_p와 V_pp의 차이를 명확히 구분할 수 있습니다.
    • BW = f_H - f_L 공식을 올바르게 적용하고, f_H를 BW로 혼동하지 않습니다.
    • 중심 주파수가 주어졌을 때 f_L과 f_H를 구할 수 있습니다.
    • Part 1 핵심 용어(주파수, 진폭, 위상, 대역폭, 스펙트럼)를 자신의 언어로 설명할 수 있습니다.
